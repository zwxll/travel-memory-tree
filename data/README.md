# 本地相册资料

公开仓库只包含空白模板。真实照片、旅行记录、纪念日期和信件均保留在本地。

首次使用，在项目根目录运行 `npm run setup`，或手动复制：

- `photos.example.js` → `photos.js`
- `user-records.example.js` → `user-records.js`

初始化只创建缺少的文件，不会覆盖已有资料。之后打开 `index.html`，通过“添加城市”导入照片并保存到本项目文件夹。

`photos.js`、`user-records.js`、`catalog.json`、`photos/` 和截图已经加入 Git 忽略规则。请勿使用 `git add -f` 强行上传这些文件。
